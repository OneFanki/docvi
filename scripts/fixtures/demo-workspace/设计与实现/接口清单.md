# 接口清单

对外只有三个接口。每个接口除了参数与响应，还写清了**不变量**——那些无论怎么改
实现都不能破的规则。

### GET /api/orders

订单列表：按状态筛选、分页排序

**权限门槛**：登录

**入参**

| 参数       | 位置  | 类型   | 必填 | 说明                                                         |
| ---------- | ----- | ------ | ---- | ------------------------------------------------------------ |
| `status`   | query | string |      | 按状态筛选（pending/paid/shipped/done/closed），缺省返回全部 |
| `page`     | query | number |      | 页码，缺省 1                                                 |
| `pageSize` | query | number |      | 每页条数，上限 100，缺省 20                                  |

**出参（关键字段，完整 schema 以 DTO 代码为准）**

| 字段    | 类型         | 说明                           |
| ------- | ------------ | ------------------------------ |
| `items` | OrderBrief[] | 订单摘要列表（不含订单项明细） |
| `total` | number       | 符合筛选的总条数               |

**不变量**

- 只返回当前登录用户的订单：用户维度在服务端强制过滤，不信任入参

### POST /api/orders

创建订单：校验并锁定库存，金额以服务端快照为准

**权限门槛**：登录

**入参**

| 参数     | 位置 | 类型             | 必填 | 说明                                               |
| -------- | ---- | ---------------- | ---- | -------------------------------------------------- |
| `items`  | body | OrderItemInput[] | 是   | 订单项（商品 ID + 数量）；同一商品重复出现会被合并 |
| `remark` | body | string           |      | 买家备注，上限 200 字                              |

**出参（关键字段，完整 schema 以 DTO 代码为准）**

| 字段      | 类型          | 说明                     |
| --------- | ------------- | ------------------------ |
| `orderId` | bigint        | 新订单 ID                |
| `status`  | string        | 初始状态恒为 pending     |
| `amount`  | decimal(10,2) | 服务端按当下价计算的总额 |

**不变量**

- 金额只由服务端计算：客户端提交的价格字段不参与结算
- 库存不足时整单拒绝（不部分成交、不超卖）（禁止）

**备注**：创建成功后同事务落 order_items；支付超时由定时任务关单并回滚库存。

### POST /api/orders/:id/cancel

取消订单：仅待支付状态可取消，库存同事务回滚

**权限门槛**：登录

**入参**

| 参数 | 位置 | 类型   | 必填 | 说明    |
| ---- | ---- | ------ | ---- | ------- |
| `id` | path | bigint | 是   | 订单 ID |

**出参（关键字段，完整 schema 以 DTO 代码为准）**

| 字段     | 类型   | 说明              |
| -------- | ------ | ----------------- |
| `status` | string | 取消后恒为 closed |

**不变量**

- 非 pending 状态一律拒绝取消（禁止）

**本次接口调整**

| 位置 | 改动                                                            | 备注 |
| ---- | --------------------------------------------------------------- | ---- |
|      | 新增 status 查询参数；不传等价于旧行为，客户端无需改动。        |      |
|      | 请求体里的 price 字段被忽略；金额一律由服务端按商品当前价计算。 |      |
|      | 支付改由支付服务直接发起，订单服务不再暴露支付入口。            |      |
