# 交付计划

本周期的目标是让下单链路在高峰期不再超卖、不再超时。

**本季度排程**

| 时间  | 事件           | 说明                          |
| ----- | -------------- | ----------------------------- |
| W1    | 需求评审       | 确认范围与验收口径。          |
| W2–W4 | 订单与支付改造 | 库存事务化 + 回调幂等。       |
| W5    | 联调与压测     | 发现 2 个阻塞缺陷，当周修复。 |
| W6    | 灰度发布       | 10% 流量观察一周。            |
| W7    | 全量发布       |                               |

**上线前检查**

- [ ] 库存扣减与订单落库在同一事务内
- [ ] 支付回调按 external_id 幂等
- [ ] 关单定时任务的批量大小已压测
- [ ] 对账脚本能解释历史差额
