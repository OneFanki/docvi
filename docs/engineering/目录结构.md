# 目录结构与依赖规则

> 真相源。改动目录结构、新增包、引入跨包引用前先读本文并跑 `pnpm check:boundaries`。

## 目标结构

```
docvi/
├── AGENTS.md                # 常驻硬约束 + 任务路由
├── SKILLS-INDEX.md          # 技能台账
├── .agents/skills/          # 项目级 skill（一能力域一个）
├── docs/                    # 长期文档（见 文档规范）
├── apps/
│   └── desktop/             # 唯一渲染层 + 桌面宿主（Electron 主进程 / preload / 渲染 / 服务进程）
├── packages/
│   ├── shared/              # 进程间契约：IPC 通道 / DocviApi / 设置 / 类型
│   ├── renderer-core/       # Markdown 管线：渲染、插件块、高亮、mermaid、主题样式
│   ├── editor/              # CodeMirror 6 编辑器
│   ├── plugin-api/          # 插件协议类型
│   ├── plugin-runtime/      # 插件清单校验与容器
│   └── server/              # 服务层：MCP / 分享 / 语料 / HTTP 原语（纯 Node）
├── deployer/                # 容器部署器（复用 packages/server）
├── scripts/                 # 构建、索引、门禁脚本
├── courses/                 # 示例内容根
└── plugins/                 # 预设插件包源码（打包时由 assemble-plugins 组装为 <包名>/<版本>/）
```

## 依赖方向（硬约束）

```
renderer ──(preload 白名单)──▶ main ──(进程边界/IPC)──▶ service ──▶ server
   │                            │
   └────── renderer-core / editor / shared ──────┘
                                  service ──▶ renderer-core（仅文本管线，无 DOM）

shared   ── 零运行时依赖
server   ── 不 import apps/desktop，不 import electron
plugins  ── 只允许 vue 作为 peerDependency
deployer ── 可 import packages/server 与 scripts/lib（复用，不复制）
```

- 「进程边界」= HTTP 或 IPC，禁止主进程直接 `import` 服务层业务代码。
- 渲染进程（纯 web）只经 preload 白名单访问宿主，禁止 `node:` / `electron`。
- 服务进程可复用渲染核心的**文本管线**，但不得引入依赖 DOM 的模块（高亮 / mermaid / 组件）。
- `scripts/lib/docs-core.mjs` 是内容模型的唯一实现，任何包都只能消费，不得复制。

## 新代码放哪

| 要写的东西                              | 位置                                 |
| --------------------------------------- | ------------------------------------ |
| 界面 / 布局 / 阅读视图 / 编辑器面板     | `apps/desktop/src/renderer/src/`     |
| 容器版宿主适配 / SPA 路由               | `apps/desktop/src/renderer/src/lib/` |
| 窗口 / 托盘 / IPC / 系统集成 / 文件操作 | `apps/desktop/src/main/`             |
| 服务进程（MCP / 分享 / 语料）           | `apps/desktop/src/service/`          |
| MCP / 分享 / HTTP 原语的共享实现        | `packages/server/src/`               |
| Markdown 渲染 / 排版 / 主题             | `packages/renderer-core/src/`        |
| 跨进程契约（通道 / 类型）               | `packages/shared/src/`               |
| 预设组件                                | `plugins/<包名>/src/`                |
| 容器编排 / 运维 API                     | `deployer/src/`                      |
| 构建 / 门禁 / 索引脚本                  | `scripts/`                           |

## 单载体规则

- 桌面能力只允许一处实现：`apps/desktop/src/main`（主进程）+ `packages/server`（服务层）。
- 同一份渲染层服务两种宿主：容器版不是第二套界面，而是同一份源码 + `lib/web-host.ts`
  提供的浏览器宿主。**禁止为容器另写界面**。
- 预设插件继续放仓库 `plugins/`（源码形态），打包时组装成服务层期望的 `<包名>/<版本>/` 视图；
  第三方插件按同一视图独立分发，不进本仓。
- 禁止再引入第二个桌面运行时（旧 Tauri 宿主 2026-10-20 删除，旧 Electron 宿主同期退役）。
