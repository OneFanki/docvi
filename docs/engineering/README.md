## 门禁命令

| 命令                    | 内容                                                      |
| ----------------------- | --------------------------------------------------------- |
| `pnpm verify`           | 非 fail-fast 全量校验（类型 / 单测 / 文档 / 技能 / 边界） |
| `pnpm typecheck`        | 组件库 + 壳的类型检查                                     |
| `pnpm test`             | `scripts/*.test.mjs`                                      |
| `pnpm docs:check`       | 文档链接、反引号路径、AGENTS.md 体量                      |
| `pnpm skills:check`     | skill frontmatter、description 长度、索引一致性           |
| `pnpm check:boundaries` | 跨包依赖方向（迁移期先守护已知规则）                      |
| `pnpm check:links`      | 示例内容死链报告                                          |

新增门禁时同步本表；门禁脚本本身也必须被 `pnpm test` 或 `verify` 覆盖关键分支。
