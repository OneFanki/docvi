# 01 · 频谱图演示

<at-tutorial-shell data-key="tutorialShell1"></at-tutorial-shell>

`<AudioSpectrumDiagram>` 把「bin 电平 → 频率轴 → 选中频段 → 峰值保持」沉淀为一张静态教学 SVG。这是**业务组件**：与音频 / 频谱领域强绑定，不在通用组件清单里；移除方式见课程首页的移除契约。

> 页面数据统一放在本章 frontmatter 的 components 段（kind 决定组件、其余键与组件 props 同名），正文用 at- 标签引用。


## 对数轴 + 选中频段 + 峰值保持

柱子按 bin 均匀排布、频率标注按对数轴映射（呈现「对数像素」的换算直觉）；`selected-band` 覆盖层把频段外柱体暗化；`peak-state` 画出峰值保持线（拖尾）。

<at-audio-spectrum-diagram data-key="audioSpectrumDiagram2"></at-audio-spectrum-diagram>

> 数据协议：`SpectrumBin = { value?, peak?, label? }` / `SpectrumScale = { mode: 'log' | 'linear', min?, max?, ticks? }` /
> `SpectrumBand = { start, end, label? }` / `SpectrumPeak = { enabled?, decayPerSec? }`（见 `plugins/audio/src/components/types.ts`）。
