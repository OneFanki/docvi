# 05 · 状态、时序与指标

<at-tutorial-shell data-key="tutorialShell1"></at-tutorial-shell>

四个「状态 / 时序 / 量化 / 时间」类组件——示意域延续订单系统与通用的服务性能场景。

> 页面数据统一放在本章 frontmatter 的 `components` 段（`kind` 决定组件、其余键与组件 props 同名），
> 正文用 `<at-组件名 data-key="键">` 引用——零 script setup，任何标准 markdown 渲染器都能读到这段结构化数据。


## 状态机：有哪些状态、怎么流转

状态与转移用 StateFlow 清单式呈现：每个状态卡列出它的出边与触发条件，`current` 高亮当前状态。

<at-state-flow data-key="stateFlow2"></at-state-flow>

## 消息时序：一步一走

请求链路用 MessageFlow 逐条走：上一步 / 下一步高亮当前消息，也可直接点击某一行跳到该步；`kind: 'return'` 以虚线渲染响应。

<at-message-flow data-key="messageFlow3"></at-message-flow>

## 指标卡组：从多少变成多少

性能 / 规模 / 质量一类量化叙述用 MetricRow：趋势箭头（`trend`）与语义色（`tone`）分开控制——耗时下降、吞吐上升都是 good。

<at-metric-row data-key="metricRow4"></at-metric-row>

## 时间轴：演进与排程

版本演进、项目排程一类时间叙述用 Timeline——`status` 区分完成（绿）/ 进行中（主色）/ 未开始（空心）/ 风险（琥珀）。

<at-timeline data-key="timeline5"></at-timeline>
